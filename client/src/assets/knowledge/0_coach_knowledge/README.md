# 乒乓球教练知识录入模板

本目录用于维护“专业教练可填写、工程可解析”的技术动作知识模板。

## 文件说明

| 文件 | 用途 |
|---|---|
| `table_tennis_action_knowledge_v2.xlsx` | 给专业乒乓球教练填写的 Excel 模板。用于沉淀技术动作定义、视频识别线索、易混淆动作区分、降级规则和诊断规则。 |

## Excel 模板怎么用

建议教练按下面顺序填写：

1. 先看 `填写说明` 和 `数据字典`。
2. 在 `动作清单` 中补充每个动作的定义、适用场景和“不属于本技术的情况”。
3. 在 `识别线索` 中填写视频里能直接看到的动作特征。
4. 在 `混淆矩阵` 中填写相似技术之间的关键区别。
5. 在 `降级规则` 中填写什么情况下不要强行判断。
6. 在 `诊断规则` 中填写“视觉证据 -> 技术问题 -> 训练建议”。

不要修改 Sheet 名和表头字段名；后续解析脚本会按这些名字读取。

## 关键 Sheet

| Sheet | 说明 |
|---|---|
| `数据字典` | 解释所有字段的含义、是否必填、填写范例和常见误填。 |
| `动作清单` | 每行一个技术动作。当前已包含 `bh_drive` 和 `fh_loop` 两个完整填写范例。 |
| `识别线索` | 给视频技术识别用的可见证据，例如引拍幅度、挥拍方向、触球阶段。 |
| `混淆矩阵` | 专门描述容易混淆的技术怎么区分，是提升识别准确度的核心。 |
| `降级规则` | 描述视频看不清、角度不对、关键证据缺失时如何降低置信度或输出 unknown。 |
| `诊断规则` | 在动作已识别后，用视觉证据映射具体技术问题和训练建议。 |
| `枚举值` | 下拉框和脚本使用的候选值，通常不需要教练修改。 |

## 脚本用途

后续需要另写一个解析脚本，把教练填写后的 Excel 转成服务端可读取的 JSON，例如：

```text
教练填写 Excel
  -> 校验必填项和 action_id 引用
  -> 生成 action_recognition_knowledge.json
  -> 视频分析技术识别 Pass 读取 JSON
```
