# 视频分析全链路追踪报告模板

> 本模板供 Claude Code 在 Topstar 项目中使用。当用户上传视频后要求「查看系统处理关键环节」时，按此模板输出完整报告。

---

## ⏰ 时区规则（重要！）

- `video_analysis.log` 中的时间戳是 **UTC**（末尾带 `Z`，如 `2026-07-20T13:14:20.008Z`）
- 用户位于 **北京时区 (CST, UTC+8)**
- **必须 +8小时** 转换为北京时间再展示

---

## 数据提取流程

```bash
# 1. 查最新任务
cd server && npx tsx -e "
const Database = require('better-sqlite3');
const db = new Database('./data/topstar.db', { readonly: true });
const rows = db.prepare('SELECT id, status, analysis_type, model, error, video_filename, created_at, completed_at FROM analysis_jobs ORDER BY created_at DESC LIMIT 5').all();
console.log(JSON.stringify(rows, null, 2));
db.close();
"

# 2. 定位该任务的所有 Stage 标记
grep -n "<jobId>" server/video_analysis.log

# 3. 用 read_file 读取 payload 行区间, 或直接 grep -A
```

## ⚠️ 注意事项

### 诊断矛盾标记
如果 Pass 2 输出与 Pass 1.5 分类存在逻辑矛盾（如 Pass 1.5 判定 `bh_drive` 置信度 0.95，Pass 2 却输出「动作幅度过小，像拨球（针对拉球练习者）」），必须在报告中以 ⚠️ 标注并说明原因。这是一个已知 bug——`issue_id` 以 `_intended_` 结尾的规则误挂了 `action_id`，不应作为正常诊断呈现。

### Notable Missing Cues
`notable_missing_cues` 字段记录「未观察到的特征」，是排除其他候选的证据，应单独展示。

### analysis_notes 必须完整展示
模型的分层推理过程（analysis_notes）必须**逐字**体现到报告中，不能只概括不展示。

#### 🧠 analysis_notes 原文

> **第1步 — 语音内容概要：** 教练全程在进行鼓励和节奏引导，如"对"、"不错"、"正好"等，在00:17处提示"用点劲儿"，无明确的技术动作指令。语音置信度：低（对于技术分类而言，仅作参考）。
>
> **第2步 — 判定方位：** 球员为右手持拍，在球台左侧用手背和反手胶皮朝向出球方向击球，判定为反手位。方位置信度：高。
>
> **第3步 — 综合研判：** 视觉上，球员站位近台，持拍手和球拍在台面以上，以前臂向前弹击为主，动作幅度小，节奏快，没有明显的下蹲、转腰和向下引拍摩擦动作。这完全符合反手拨球（bh_drive）的特征。
>
> **第4步 — 最终 action_id：** bh_drive。

#### 分类结果

| 候选动作 | 概率 |
|---------|------|
| **bh_drive（反手拨球）** ✅ | **0.95** |
| bh_block（反手挡球） | 0.05 |

**证据列表：**
- 球员在反手位击球，手背朝向出球方向
- 持拍手和球拍在台面以上，引拍幅度小
- 以前臂向前弹击为主，撞击多于摩擦
- 击球节奏快，身体重心起伏小，无明显蹲起动作

**排除线索：**
- ❌ 没有明显的下蹲和重心下压（排除反手拉球）
- ❌ 球拍没有明显低于球台面的引拍（排除反手拉球）
- ❌ 没有手腕内扣后外展的摩擦动作（排除反手拧拉）

#### 决策确认

| 项目 | 值 |

| 时间点 | 问题 | 根因 |
|--------|------|------|
| 00:00-00:53 | 🟡 肘部不稳，导致拨球方向控制差 | 肘部左右晃动，出球方向不稳定 |
| 00:00-00:53 | 🟡 反手拨球总是下网 | 击球点偏低，拍面前倾过度 |
| 00:00-00:53 | 🟡 拨球力量小不够快 | 前臂弹击不明显、手腕过度参与 |

**改进建议：**
1. 💡 把肘部固定在身体前方，只让前臂以肘为轴向前弹出。
2. 💡 击球点太低了！在球弹起的上升期出手。同时检查拍面是否过于前倾，稍微亮一点拍面往前推。
3. 💡 拨球的力量80%来自前臂以肘为轴的快速弹出，手腕只是微调方向。练习时感受弹出去的爆发感。

## 故障排查备忘

当用户报告视频分析结果异常时：

```bash
# 0. 先确认服务端是否活着
curl -s -o /dev/null -w "%{http_code}" http://localhost:3001

# 1. 查最近任务状态
cd server && npx tsx -e "
const Database = require('better-sqlite3');
const db = new Database('./data/topstar.db', { readonly: true });
const rows = db.prepare('SELECT id, status, analysis_type, model, error, video_filename, created_at, completed_at FROM analysis_jobs ORDER BY created_at DESC LIMIT 5').all();
console.log(JSON.stringify(rows, null, 2));
db.close();
"

# 2. 查最新 Stage 标记
grep -n "JOB_START\|JOB_FAILED\|JOB_SUCCESS" server/video_analysis.log | tail -5

# 3. 若失败，定位失败 Stage
grep "FAILED\|ERROR" server/video_analysis.log | tail -10
```
