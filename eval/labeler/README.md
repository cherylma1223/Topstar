# 评测集标注工具（本地网页版）

给教练用的标注界面：左边选视频，右边看片 + 下拉/勾选标注，**改动自动保存**回
`eval/labels/annotations.csv`（和 `npm run eval -- validate`、`npm run eval -- run` 读的是同一个文件）。

不引入新依赖、不连数据库、不调用任何模型，只在本机跑一个小服务。

---

## 一、启动

```bash
cd server
npm run labeler          # 默认 http://127.0.0.1:3100，会自动打开浏览器
```

首次启动会把当前标注表读进来。关掉终端或按 `Ctrl+C` 结束。

可选环境变量：

| 变量 | 默认值 | 用途 |
|---|---|---|
| `LABELER_PORT` | `3100` | 端口被占用时换一个 |
| `LABELER_HOST` | `127.0.0.1` | 想让同一局域网的教练电脑访问，改成 `0.0.0.0` |
| `LABELER_LABELS` | `eval/labels/annotations.csv` | 标注文件路径 |
| `LABELER_VIDEOS` | `eval/videos` | 视频目录 |
| `LABELER_NO_OPEN` | 未设置 | 设成 `1` 则不自动打开浏览器 |

---

## 二、界面怎么用

1. **左侧**：视频列表 + 进度（已标注 / 总数）。可按「未标注」「缺视频」筛选。点条目切换。
2. **中间**：视频播放器。拖到有效击球的开始处点「设起点」，到结束处点「设终点」；可标多段，点片段上的 ✕ 删除。
3. **动作类型**：下拉选择，13 个动作都带中文名；没有有效击球选「无效视频」。
4. **教练语音**：有清晰口令 / 无口令或听不清 / 未标注（决定我们能不能保留「听声音」的能力）。
5. **主要问题点**：只列出**当前动作**对应的诊断规则，勾选即可；确认没问题就勾「确认没有问题」。
6. **拍摄条件**：机位 / 光线 / 画质 / 其他，勾选。
7. **备注**：选填，点开展开。

改动后右上角会显示「保存中 → 已保存 HH:MM:SS」。**每次保存都会先备份**上一版到
`annotations.csv.bak`，并在写入前用评测脚本同一套规则校验，有问题不会落盘（页面会列出原因）。

快捷键：`←` `→` 上一条/下一条，`空格` 播放/暂停，`S` 设起点，`E` 设终点。

---

## 三、添加视频

把视频文件放进 `eval/videos/`，点右上角「刷新」，再点「＋ 添加视频」，
列表里会出现还没加入的视频，点「添加」即可（`video_id` 由文件名自动生成，不用手输）。

> 视频体积大，`eval/videos/` 已在 `.gitignore` 里，不进 git；换电脑要手动拷贝。

---

## 四、视频打不开怎么办

`.MOV` 在 Chrome 里可能不支持。两个办法：

1. 用 **Safari** 打开本页；
2. 先转成 mp4（需要 ffmpeg）：
   ```bash
   ffmpeg -i 原视频.MOV -c:v libx264 -crf 23 -c:a aac 新视频.mp4
   ```
   然后把 mp4 放进 `eval/videos/`，在标注工具里换成这个文件。

---

## 五、标注完做什么

```bash
cd server
npm run eval -- validate                                  # 复核格式与 ID
npm run eval -- run --label gemini-baseline --repeat 3 --yes   # 采 Gemini 基线（会产生费用）
```

> 标注一旦开始对比模型就不要随便改；要改标注就新开一个版本，否则新旧结果没法比。
